Projeto em destaque

● Em produção Código privado Projeto pessoal · solo

Nocker — super-app de finanças pessoais

Um app de finanças que construí sozinho, de ponta a ponta: app mobile, API própria, banco, autenticação, IA e o processo de publicação. É o projeto onde juntei tudo que sei e aprendi o que faltava.

  • Full-stack sozinho: app em React Native + Expo, API em FastAPI e banco no Supabase (Postgres).
  • IA pelo backend (SDK oficial da Anthropic) para organização financeira — a chave nunca chega ao celular do usuário.
  • Open Finance via Pluggy e captura automática de PIX com módulo nativo Android em Kotlin.
  • Autenticação própria em JWT + login Google; deploy em Docker no Render; builds mobile com EAS.
  • Design system com dois temas de igual peso, claro e escuro, conferidos por contraste (WCAG).
  • Hardening de segurança e o caminho completo até a publicação na Play Store.
